### LVX

编写一个 Go 程序，实现以下功能：

1. 不断让用户输入整数（输入 `0` 表示结束输入）；
2. 使用 `for` 循环统计输入数字的总和与个数；
3. 定义一个函数 `average(sum int, count int) float64` 用于计算平均值；
4. 根据平均值输出结果：
   - 若平均值 ≥ 60，输出“平均成绩为 xx.xx，成绩合格”；
   - 否则输出“平均成绩为 xx.xx，成绩不合格”。

示例输入：

```
请输入一个整数(输入0结束): 80
请输入一个整数(输入0结束): 90
请输入一个整数(输入0结束): 40
请输入一个整数(输入0结束): 0
```

示例输出：

```
平均成绩为 70.00，成绩合格
```
